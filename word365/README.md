# 背单词365 · 桌面版 v2.0

原生 HTML/CSS/JS 单页应用，无框架、无构建。**双击 `index.html` 即可使用**（file:// 协议可用）。

> 365天，每天进步一点

## 快速开始

1. 双击 `index.html`（或用任意静态服务器打开）
2. 首页点「开始学习」进入今日计划
3. 数据只存本机 localStorage（key：`w365.db`），可在「我的 → 数据」导出/导入 JSON 备份

## 功能总览

- **五本内置词书（460 词，跨书零重复）**：四级 core / 六级 core / 考研 core / 雅思 core（各 100 词）+ 职场与求职（60 词）。内置词库为精编版，完整考纲词表可通过自制词书导入。
- **学习页四模式**：单词快过（3D 翻转闪卡）/ 写出英文（空格逐字母提示）/ 英文选义 / 单词对对碰（放松小游戏，不评级、不计额度、不进错词本）。
- **复习阶梯（SRS）**：固定间隔 `[1, 2, 4, 7, 15, 30, 60]` 天；「认识」升一级，lvl≥3 且间隔≥7 天记为「已掌握」；「模糊」= 28 小时后重来；「不认识」= 10 分钟后重来并进错词本。
- **错词本**：模糊/不认识、拼写与选义答错自动收进；错词连对 2 次自动毕业移出；支持手动移出与一键清空。
- **每日额度**：新词默认 20 / 复习默认 60，全局日计数、跨词书共享。
- **每日学习时长可配置（N4）**：设置页可选 10 / 20 / 30 分钟，副标题随档位集合自动派生；系统按所选时长为每日新词量封顶，并在周度视图给出只读「建议调档」提示（只提示、不自动改写额度）。空打开日的完成率显示中性态，不报 0% / NaN。
- **默写阶梯（N2）**：默写类题型按记忆等级自动升阶，「我的」页可切「自动 / 手动」；仅改变题型的再见方式，不改变复习到期时间（SRS 阶梯恒为可回退基线）。
- **自制词书**：粘贴单词表创建，支持「每行一个单词」（自动匹配内置词库）与「单词 | 音标 | 释义 | 例句 | 例句翻译」两种格式。
- **学习统计**：26 周热力图、最近 14 天柱状图、连续天数 / 总正确率 / 已学词数 / 错词本卡片。
- **已掌握词抽测**：在「学习统计」页主动发起，从已掌握词中随机抽 10 个默写英文，检验「能认」是否等于「会写」。结果只陈述「仍是已掌握 / 待重读」的页数，不出现分数、不改动 `lvl` / `due` / 错词本。使用条件：已掌握词 ≥ 10 且距上次完整抽测 ≥ 14 天；中途合上不记入结果、不消耗机会。
- **待重读清单**：抽测未写对的词在统计页可查看，一键进入既有「写出英文」复习，或手动标记已重读。
- **近 28 天学习节律**：统计页展示有效学习日、空打开日、间隔中位数与最长间隔；纯读取 `db.days`，不新增埋点、不写入任何字段。
- **抽测记录**：查看最近 10 次抽测的日期、抽看页数、仍是已掌握页数与待重读页数；只陈述计数，不评分。
- **装订记录（本机凭据）**：每掌握 50 个词且完成过一次抽测，留下一张本机凭据；只随整库 JSON 备份带走，不生成图片、不分享，可本机删除（删除不回退累计页数、不重发同编号）。
- **星标精读**：一键把加过星标的词送入既有「写出英文」模式复习，复用既有 `scope=star` 路由，不新增交互。
- **记忆强度（可选叠加）**：每次作答以加法在本机词条记录一条事件；默认关闭，复习仍按固定阶梯 `[1,2,4,7,15,30,60]` 天进行。显式开启后，按作答历史估计的可解释强度决定到期时间，关闭即逐字段回到固定阶梯（事件保留、不删除）。强度为只读估计，不采用实时训练模型、不展示百分比，也不改变「已掌握」判定。
- **桌宠「单词小鲸鱼」**：每评完一个词吃一口；今日目标 = 每日新词上限；累计每 120 口升 1 级；可拖动（记忆位置）、单击看口数、右键弹菜单。
- **快捷键**（学习页，⌨ 按钮查看完整表）：
  - 单词快过：`空格` 翻面 · `Enter` 翻面/认识 · `1` 不认识 · `2` 模糊 · `3` 认识(背面)/星标(正面) · `R` 重读 · `← →` 换词 · `Esc` 退出
  - 写出英文：`空格` 提示 · `Enter` 提交/下一词 · `R` 重读
  - 英文选义：`1–4` 选择 · `Enter` 下一词 · `R` 重读
  - 通用：`Esc` 关弹窗；评级后 2.6 秒内可撤销；180ms 防误触

## 已知限制

- 单词发音依赖有道 TTS 在线接口，离线时自动回退到本机 `speechSynthesis` 朗读（会提示「发音加载失败，已切到本机朗读」）。
- 数据存于浏览器 localStorage，清除浏览器数据会丢库，请定期「导出 JSON」备份。
- 学习进度全局共享（一词一记录），词书只决定收词范围；旧版「词书::单词」键的备份导入时会自动幂等迁移。
- 内置词库为精编版（每本 60–100 词），如需完整考纲请用自制词书导入完整词表。
- 已掌握词抽测的结果只写入 `db.exam`，**不改变复习节奏**（`lvl` / `due` / 错词本 / 星标均不动）；「待重读」是独立清单，需手动标记已重读或进入复习，不会自动清理。抽测记录与清单随整库 JSON 备份一起导出/导入。
- 装订凭据只在打开「学习统计」页时结算（其余页面不触发）；若已掌握页数一次跨过多个 50 的倍数，每次访问最多补一张，需多次访问逐张补齐。`db.binding.totalPages` 与 `issuedNoMax` 单调不回退。
