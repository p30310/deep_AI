## 1. 背景 / Problem / Goal / Non-goals

### 1.1 Problem

**【实测】** 词库 460 词中约 **162（35%）** 是多义词，但一词一卡只考一个笼统释义：词条的释义整体存于一个 `t` 字符串（如 `account: 'n. 账户；描述'`、`act: 'v. 行动；表演 n. 行为'`、`admit: 'v. 承认；准许进入'`、`advance: 'v./n. 前进，进步'`，`js/data/cet4.js`），卡片与抽测直接把整串 `t` 当作单一释义展示/提示（`app.js:1006` def-line、`app.js:1178` type-question、`app.js:1716` 抽测 meaning）。

**【实测】** 抽测会话以词为粒度生成与判定：`startExam`（core.js:1325-1346）按 `dayKey(at)` 哈希种子洗牌取词 key，`gradeExam`（core.js:1356-1376）按 `norm(answer)===norm(w)` 判对错；判定与 SRS 状态均按 `w::` 词粒度（core.js:34 `wordKey`）。

**【推断】** 单一笼统释义导致「认识这个词却只会一个意思」：用户能想起 `account` 的「账户」，却未必记得「描述」；抽样只考整串 `t`，多义收益未被利用，而拆卡又会冲击 `w::` 主键、SRS 状态、错词本、星标与备份迁移（D-037 已否决拆卡）。

### 1.2 Goal

1. **卡片展示全部义项**：学习卡 / 复习卡把 `t` 字符串拆成可读的有序义项列表展示，原有音标 / 例句 / 例句翻译 / 发音不破坏。
2. **抽测与默写随机抽一个义项来考**：拿到多义词后随机抽一个义项作为提示/考点，判定按所选义项，**不拆卡、不动 `w::` 主键、不动 SRS 状态粒度**。
3. **可复现、纯函数、零 SRS 副作用**：抽义项同词同种子结果一致（种子 = 日期 + 词，避免刷题）；义项解析 / 抽取 / 判定均为纯函数；不产生义项级 `lvl/due`，错词本仍按词，C10「抽测不改 lvl/due/错词本/星标」维持。

### 1.3 Non-goals（可枚举、逐条可判定）

1. **不拆卡**：维持一词一卡，不引入义项级卡片或义项级主键。
2. **不改 `db.words` 粒度**：不新增义项级记录，不改 `w::` 主键体系（core.js:34）。
3. **不改 `lvl/due/st`**：SRS 状态仍按词，抽义项考不产生义项级进度。
4. **SCHEMA 恒 3**：不抬版本、不新增任何持久化字段（义项从 `t` 实时派生）。
5. **不做义项级进度**：不为单个义项记录掌握度 / 到期 / 错词标记。
6. **不碰 #015 强度字段语义**：不改 `evts` / `strengthMode` / 强度函数与叠加引擎的任何口径（D-037 立项内两方向边界）。
7. **不改固定阶梯 `LADDER_DAYS` 与 `rateWord` 三分支**（C4 方向既有红线）。
8. **词库只读**：不写 `js/data/*.js`，自制词书导入格式不变，旧备份向前兼容。
9. **不做独立 UI 页面 / 路由**：本卡只在既有卡片与抽测/默写流程内增强，不新增页面。

## 4. 关键业务规则 / 不变式

> 本章为【规划】；默认假设未拍板即按此执行（Open 见 §5）。精确切分规则与函数签名由 G2 契约定。

### 4.1 义项派生（不持久化）

- 义项**只从 `t` 字符串实时派生**，不写入 `db`、不缓存到任何持久化字段；`sensesOf` 为纯函数、不修改入参词条。
- 切分优先级：**全角分号 `；` 优先 → 多词性标签识别 → 斜杠 `/` 降级**；`text` 不含前导词性标签，`pos` 缺省时省略；顺序按 `t` 原文顺序（OQ-01）。
- 词性标签沿用与中途切换均须保留（如 `act` 的 `表演` 继承 `v.`、`行为` 切换为 `n.`）。

### 4.2 抽义项与复现

- 种子 = **日期 + 词**（建议 `dateKey + wordKey` 字符串），复用 `startExam`（core.js:1332-1339）的 charCode 哈希 + xorshift 确定性策略，**不使用 `Math.random`**。
- 同词同种子 → 同一义项索引；换日期 / 换词 → 可得到不同索引（避免刷题）；选中义项仅存**会话内存**，不写 `db`。

### 4.3 判定与状态边界

- 抽测 / 默写保持既有「看中文释义提示 → 写英文词」答题形态；所选义项作为**提示文本**，答案仍与词条英文词 `w` 比对；判定结果绑定所选义项索引与文本（方向默认假设见 G2 契约 §需 G0 裁决备案项）。
- 判定为纯函数；错词本 / 星标 / `db.exam` 仍按**词**粒度，不产生义项级进度；`lvl/due/st` 判语义与 C10 抽测不改写状态维持。

### 4.4 状态不变式（红线）

- `w::` 主键体系、`db.words` 粒度、C1 一词一态不变；`SCHEMA` 恒 3、`LADDER_DAYS` 恒 `[1,2,4,7,15,30,60]`；#015 强度字段语义零改动。
