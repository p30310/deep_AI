## 2. 逐项验收标准

> 优先级定义：P0 = 必须交付；P1 = 阶段一列入口但可分批；本阶段三项均为 P0/P1 混合，详见各条。
> 每条验收均为可测试、可验收（给定输入 → 断言输出）。

### 2.1 方案 C ｜ 任务配比 + 防积压熔断 + 回归保护（v2 §3.1 方案 C，RICE 76.5，P0）

**核心机制**
- 每日计划由三旋钮决定：① 可用时长（10/20/30 分钟）② 复习队列压力 ③ 新词引入速度。
- 复习压力 > 阈值 → 自动暂停新词，并明确告知「今天先把旧账清了，明天加新词」。
- 压力正常 → 按 **7:3 复习/新词配比**（复习优先，新词约占 30%）。
- 回归保护：中断 ≥ 3 天回归时，不展示全量积压；筛「记忆强度最低 + 考纲高频」≤ 40 词作为「今日重建任务」；剩余积压摊到 3–5 天；首屏正向文案。
- 每日上限熔断：超设定上限时低优先级词自动顺延，不做清零式压迫。

**验收条目**
- **C-AC1（回归触发）**：`(今天 − db.returnGuard.lastSeen) ≥ 3 天` 且积压词（`reps>0 && due≤now`）≥ `N`（阈值见 Open-3）时，首屏**不**展示全量积压，改展示「今日重建任务」区块。
- **C-AC2（重建包上限）**：重建任务包 `≤ 40 词`；筛选规则 = 记忆强度最低（阶段一用 `lvl` 低 + `due` 越紧迫优先的代理）叠加考纲高频（高频表来源见 Open-6）。
- **C-AC3（平滑摊派）**：剩余积压以 3–5 天平滑分派到后续日计划，**不**一次性倒出；首页文案逐字（见 §4 条目 3，待确认逐字）。
- **C-AC4（熔断暂停新词）**：复习压力 > 阈值时，当日新词数 = 0，并展示文案「今天先把旧账清了，明天加新词」。
- **C-AC5（7:3 配比）**：压力正常日，新词 : 复习 ≈ 3 : 7（新词约占当日额度 30%，复习占 70%，复习队列非空时优先消化复习）。
- **C-AC6（上限顺延）**：当日额度达上限后，低优先级词（如新词）顺延至次日；**不**出现「清零 / 你落后了」式压迫文案；护栏指标「日均使用时长」不恶化（v2 §七 护栏）。
- **C-AC7（lastSeen 维护）**：每日任意作答/打开即更新 `db.returnGuard.lastSeen`；回归判定以此为据，而非「断签 N 天」展示式文案。

### 2.2 方案 I ｜ 目标 → 计划自动拆解（v2 §3.3 方案 I，RICE 53.3，P1 但阶段一冷启动）

**核心机制**
- 首次使用只问三件事：目标（考试类型/自由学习）+ 截止日期 + 每日可用时长。
- 系统输出可解释计划：「距考试 128 天，词库 3600 词，扣除已掌握约 900 词，需每日新学 21 词 + 复习约 60 词，约 22 分钟」。
- 每周自动再平衡：完成率 < 70% → 主动降量并调整目标预期（非内疚式）；> 95% → 智能加速提示。

**验收条目**
- **I-AC1（入口与落库）**：首次启动进入「目标三问」引导（或「我的」页可重做，见 Open-4）；完成后 `db.goal` 落库（含 type / deadline / dailyMinutes / createdAt）。
- **I-AC2（可解释计划文案）**：三问完成后，首页/计划页展示可解释计划卡，六要素齐备：① 距目标天数 ② 词库总量 ③ 已掌握扣除数 ④ 每日新学数 ⑤ 每日复习数 ⑥ 预计每日时长（文案逐字见 §4 条目 7）。
- **I-AC3（推导可复算）**：`每日新学 = ceil((词库总量 − 已掌握) / 剩余天数)`；`每日复习 ≈ 现有 due 队列规模估算`；`预计时长 = 任务词数 × 单词约 30–40 秒`。公式与文案数值必须一致、可被单测复算。
- **I-AC4（每周再平衡）**：每 7 天滚动评估完成率（完成率口径见 Open-7）；< 70% → 自动降量并弹非内疚式提示（文案见 §4 条目 8）；> 95% → 提示「你比计划快 X 天」智能加速。
- **I-AC5（安全边界）**：再平衡仅调整 `dailyMinutes / freshLimit` 建议值，**不**改动已生成的 `words` 进度记录；用户可关闭自动调整（见 Open-5）。

### 2.3 方案 J ｜ 词汇量基线 + 难度自适应（v2 §3.3 方案 J，RICE 53.3，P1）

**核心机制**
- 3 分钟自适应测试：按词频分层抽样，答对升级、答错降级，收敛到真实水平 ±300 词。
- 测试结果批量标记「毕业」裁剪词库，学习起点从 i+1 开始（首日不再面对 abandon）。
- 每 2 周重估；提供「太简单/太难」一键反馈作为人工干预通道。

**验收条目**
- **J-AC1（测试题量上限）**：自适应测试题量有硬上限（3 分钟内可完成，约 20–30 题，具体见 Open-2）；按词频分层（复用内置 460 词或另建抽样表，见 Open-2）。
- **J-AC2（阶梯收敛）**：测试采用阶梯式——答对升难度、答错降难度，最终收敛区间 **±300 词**（以估计词汇量水平为收敛点）。
- **J-AC3（批量毕业裁剪）**：测试后，水平线以下/已掌握词批量标记「毕业」（`graduated:true`，区别于 SRS 自然 `st='known'`），移出每日新词计划；学习起点从 i+1（首个未毕业词）开始。
- **J-AC4（周期重估 + 反馈）**：每 2 周（14 天）自动重估（基于作答表现）；提供「太简单 / 太难」一键反馈入口，反馈触发即时重估或人工干预。
- **J-AC5（数据兼容）**：`db.baseline = {level, testedAt, words:[...], reestimateAt}` 落库；导入/导出 JSON 兼容，不破坏旧键格式迁移（core.js `migrateOldKeys`）。

## 3. 数据契约新增（写入 `w365.db`）

> 现有顶层键：`schema / createdAt / updatedAt / settings / petState / books / customBooks / words / days`（core.js `defaultDB`）。
> 现有 `settings`：`freshLimit(20) / reviewLimit(60) / accent / rate / theme / pet / autoNext / coachSeen`。
> 现有 `word` record：`w / lvl / st / due / reps / correct / wrong / wfix / star / note / last / first / lastRating / srcBook`。
> 以下**仅列字段名与含义**，具体类型/默认值由架构师定；**不得与现有键冲突**。

### 3.1 顶层新增
| 字段 | 含义 | 归属方案 |
|---|---|---|
| `db.goal` | 用户目标：`{type, deadline, dailyMinutes, createdAt}`（type 枚举见 Open-1） | I |
| `db.plan` | 计划推导快照：`{derivedAt, totalWords, mastered, dailyFresh, dailyReview, estMinutes, daysLeft}`（与 I-AC2 六要素对应） | I |
| `db.baseline` | 词汇量基线：`{level, testedAt, words:[已毕业词key], reestimateAt}` | J |
| `db.returnGuard` | 回归保护：`{lastSeen, backlogCount, rebuiltAt, rebuildWords:[...], spreadDays}` | C |
| `db.onboarding` | 首启引导状态：`{step, completedAt, skipped}`（三问+测试是否完成） | I/J（冷启动编排） |

### 3.2 `settings` 内扩展（不新增顶层键）
| 字段 | 含义 | 归属方案 |
|---|---|---|
| `settings.dailyMinutes` | 每日可用时长旋钮：10 / 20 / 30（分钟），替代/补充 `freshLimit` 派生 | C / I |
| `settings.returnDays` | 回归保护触发天数阈值，默认 3（Open-3 确认） | C |
| `settings.rebuildCap` | 重建任务包上限，默认 40 | C |
| `settings.reviewRatio` | 复习/新词配比，默认 0.7（复习占 70%） | C |
| `settings.pressureThreshold` | 复习压力熔断阈值（积压词数或额度占比，Open-3 确认） | C |
| `settings.autoRebalance` | 每周再平衡是否自动调整，默认 true（Open-5 确认） | I |

### 3.3 `word` record 内扩展
| 字段 | 含义 | 归属方案 |
|---|---|---|
| `word.graduated` | 方案 J 测试批量毕业标记（true 即裁剪出每日新词计划）；与 SRS 自然 `st='known'` 区分 | J |

### 3.4 `days[dayKey]` 内扩展（用于北极星埋点）
| 字段 | 含义 | 归属方案 |
|---|---|---|
| `days[dk].planTarget` | 当日计划任务总数（用于「次日有效复习完成率」= 完成数/planTarget） | 北极星（C/I 共用） |

## 6. 待确认问题（写实清单，须评审前闭合）

1. **方案 I 考试类型枚举**：`type` 具体枚举值有哪些（四六级 / 考研 / 雅思 / 托福 / 职场 / 自由学习？）；各类型对应默认词库与每日时长默认值如何映射？
2. **方案 J 测试词表来源**：自适应测试分层抽样表是**复用内置 460 词**，还是**另建分层抽样表**？460 词覆盖面是否足以收敛到 ±300 词？词频分层口径（CET4→CET6→考研→雅思→职场？）如何定？
3. **方案 C 回归具体数值与首屏文案**：
   - 「中断 ≥ 3 天」按自然日还是 `lastSeen` 时间戳？
   - 积压阈值 `N`（C-AC1）具体值？
   - 重建包上限 40（C-AC2）是否锁定？
   - 首屏回归文案逐字：v2 §四③表格为「欢迎回来，帮你重排了，今天 18 分钟」，方案 C 正文为「帮你重新排好了，今天 18 分钟就能追上」——**两处不一致，需统一**。
4. **首次三问入口时机**：首次启动**强制**进入，还是允许在「我的」页**重做**？是否允许「跳过 / 稍后」？跳过后的首屏回退到现状还是空白计划？
5. **每周自动再平衡形态**：做成**自动弹窗**还是仅 **toast/卡片提示**？`settings.autoRebalance` 默认开启是否合适？用户能否一键关闭自动调量？
6. **方案 C「记忆强度最低 + 考纲高频」代理定义**：阶段一无 `S` 值，`记忆强度最低`如何用 `lvl`+`due` 代理？「考纲高频」表从哪来（复用词书顺序？还是需补词频字段）？
7. **北极星埋点口径**：「次日有效复习完成率」中「有效完成」的阈值（完成当日 `planTarget` 的百分之多少算有效？是否含新词+复习合并口径）？`days[dk].planTarget` 由谁在何时写入？
8. **方案 J 与方案 I 的衔接顺序**：v2 §六 阶段一顺序为 C→J→I，但冷启动实操上 I（三问）应在 J（测试裁剪）之前还是之后？首屏「花 3 分钟定制计划」是否把 I+J 串成一次性引导流？
