> **用途**：任何任务被召唤时，按本页定位分组 → 读该组 `BOUNDARY.md` → 回执 → 认领 → 开工。本页是唯一入口，不重复总纲正文。

## 1. 召唤流程（固定 5 步）

1. 读总纲 §11「召唤协议」，确认任务是否触发分组机制；
2. 查本页 §2「默认调用映射」定默认组与协作组；
3. 读目标组 `BOUNDARY.md` 的 8 节（职责/触发/产出/输入/可写/禁写/DoD/依赖）；
4. 回执 6 项（任务卡号、写入文件集、基线复跑、依赖就绪、产出落点、是否需裁决），并在 §5 认领表登记；
5. 完成后更新认领表状态 + 在目标组 BOUNDARY.md 的「执行登记」追加一行。

> **不触发**：单一事实问答、只读解释、与 365 无关的任务。此时不派组，直接回答。
