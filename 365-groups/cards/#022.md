## 设计定调（frontend-design Step 1，交付前锁定）
- **Purpose**：把一个**功能性失败**（主按钮文字读不清）修掉，同时不让产品看起来像换了皮。
- **Tone**：沿用既有的 Industrial + 克制的方向——不做视觉重启，只做**色阶层级修正**：图形填充留给 `--brand`（热力图/进度条/开关/加点气泡），**文字可读的填充**交给新令牌 `--cta-*`。
- **Constraints**：不动品牌主色 `--brand #3cae7c`；暗色反相（浅底深字）；所有颜色走变量；四态（default / hover / active / focus-visible）都要成立。
- **Differentiation**：主按钮变成「更深的绿」而不是「更亮的绿」——与 #021 加深后的文字绿形成同一色阶，整个界面的绿从"荧光"收敛为"沉稳"，反而更像一支被设计过的品牌色。

### C. 为什么不选「保留亮绿 + 改墨字」
`--ink #22303c` 压在 `#3cae7c` 上是 4.88:1，技术上能过；但那会让主按钮从「实心品牌按钮」变成「浅绿块 + 深字」，与 `.btn`（描边按钮）、`.badge`（浅底胶囊）在同一页里难以区分层级。**填充深度**比**文字颜色**更能表达「这是主操作」，故选择加深底、保留白字承诺。

### D. 状态与降级
- default / hover 用两组令牌；`:active` 仍为既有 `transform: scale(.97)`；`:focus-visible` 走全局 2px 描边（`--brand`），在深底按钮外仍可见；未新增 `:disabled`（全站未使用禁用态主按钮）。
- 未新增动效，`prefers-reduced-motion` 不受影响。

### E. 未闭合
- `.book-cover` 白字压在按词书内联的封面底色上（非令牌），需逐书审计色值 → 未立项。
- 真实浏览器观感（主按钮整体变深）未由 agent 目视，已开预览留用户确认；数值层已锁定。
