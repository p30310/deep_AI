## 0. 范围与定调

零按钮、零筛选、零路由、零 hover 反馈——不得出现任何"看起来可点"的元素（无 `›`、无手型、无下划线、无 `.btn`）。形态：**一句事实（比例内嵌句中）+ 一行口径副标 + 一行只读尾注**，全宽 `.card`，**不是第五张 `.stat-card`**。反面清单：不圆环、不进度条、不评级色、不奖杯/星级、不用"0%／100%"占位、不做趋势箭头/对比上一期/达标进度条。

## 1. 展示位：**统计页**，独立全宽 `.card`
**位置：`renderStats` 内「近 14 天有效完成率」卡之后、`strengthEntryHtml()`（仪表盘入口卡）之前**，前置既有 `.section-gap`（18px）。叙事顺序：概览 → 输入侧三卡（热力图／14 天／完成率）→ **结果侧（本块）** → 记录侧（抽测／节律／装订／星标）；位置本身承担"不同性质"的标记（D-054 不靠颜色区分）。

**不进 `.stat-cards` 栅格**：`.stat-cards` 是 `repeat(auto-fill,minmax(180px,1fr))`，980px 内容宽下生成 5 条轨道——加第 5 个 tile 填的是**本就空着的**第 5 轨，四块**宽度不变**；真代价是**行高**：grid 行高等于最高项，1440 档新 tile 在 184.8px 轨道内主句折 3 行 → 高 ~208px，现有四卡仅 ~111px → **四卡被拉伸到 208px、每卡底部多出 ~98px 死白**。独立块则四卡宽高**逐像素零改动**。

**不进仪表盘的三条理由**：① 仪表盘整页以「记忆保持率 · 散点图」为题、侧栏写「保持率估计 = 强度分(0–6) ÷ 6」，把**实测**指标放进那页＝摆在"保持率"射程正中，正撞 D-054④ 禁混名红线；② 其 `.overview` 是 5 格**评级条**（`.metric.hi/.md/.lo`＝记得牢/在巩固/需复习，青绿/青灰/琥珀橙），"不评价好坏"的实测 % 塞邻位会被读成第四档位；③ 仪表盘是 `file://` 独立页、需 `打开仪表盘 ›` 再开新标签页，而冷启动/样本不足是**主场景**，可达性必须短。（数据通路本身是通的：仪表盘以 `Core.loadDB()` 读同一 `localStorage['w365.db']`，只读不写——这条不是技术限制，是设计判断。）

## 3. 三态（冷启动与样本不足＝主场景）

契约返回 `state` 三态（`empty`／`insufficient`／`ok`），阈值 **10 写死在契约层**，UI 只认 `state`、**不得硬编码第二份门槛**。`rate`＝未取整浮点；`rate===null`（无样本）时**不是 0**。

| 态 | 条件 | 主句（逐字键） | 比例位 |
|---|---|---|---|
| ok | samples ≥ 10 | `lead(M,P)`：已观察到的 {M} 个词里，有 {P} 在观察窗口过去后仍然答对。 | 行内 `.ret-num` 显示 {P} |
| insufficient | 1 ≤ samples < 10 | `leadInsufficient(M,min)`：样本 {M} 个词，满 {min} 个才显示比例。 | **整块消失** |
| empty | samples = 0 | `leadEmpty(N)`：还没有可观察的复习：某个词隔 {N} 天以上再考一次、并且那一次也记下来，这里才会有数据。 | **整块消失** |

**insufficient/empty 硬约束**：不得出现 0%、100%、`—`、`0`、进度环/进度条。理由：N=1 时 rate 只能是 0% 或 100%，N=3 亦只是 0/33/67/100 这类离散值，**任何百分比在此都误导**；只有"样本量 + 为什么还没有比例"的事实句才诚实。**empty 态更不显示"0 个词"**（0 是"没数据"不是"表现差"），看起来必须像"还没开始"而非"失败"。

**`<1%` 规则（v1.2 补读法）**：**判定必须读未取整的 `rate`，不可读 `ratePct`**——`ratePct = Math.round(rate*100)` 会把「实际有保留、只是不足 1%」与「真的是 0%」压成同一个 0，而 0% 会被读成"全忘"。正确读法：`rate > 0 且 ratePct === 0` → 显示 `<1%`（实测：1/1000 → rate 0.001 → ratePct 0 → 显示 `<1%`，`&lt;1%` 转义完好；1/200 → ratePct 1 → 显示 `1%`）；`rate === 0` → 显示 `0%`。**真实 0%（0/10、state=ok）照实显示 `0%`**——分母够时 0% 是事实，不是"没数据"，与 insufficient 态的"无比例位"是两回事，不得混淆。**任何路径不得出现 NaN／Infinity／undefined**。

## 4. 副标三段条件拼接（D-055③）

单位全部「**词**」（一词一票、词级去重，**不是"次"**）。三段以 ` · ` 连接：**窗口段** `subWindow(N)`＝「窗口 {N} 天」**始终显示**；**样本段** `subSample(M)`＝「样本 {M} 个词」**仅 M>0**；**缺口段** `subPending(C)`＝「另有 {C} 个词尚未到观察期，未计入分母」**仅 C>0**。
**M=0 且 C=0 → 副标只有「窗口 30 天」一行**，不出现「样本 0 个词」这种"没数据"式计数。**M=0 且 C>0**（用户有词但都不够间隔，如实例：12 词待观察）→ 副标为「窗口 30 天 · 另有 12 个词尚未到观察期，未计入分母」——此时 empty 主句解释"还没有可观察的复习"，副标解释"为什么还没有"，两者不重复、不打架。

**字段绑定（v1.2 补，绑定 G2 契约八键）**：契约返回 `{ window, samples, retained, lost, pending, rate, ratePct, state }`。**文案键映射**：`title`（h3）／`lead(M,P)`（主句）／`leadInsufficient(M,min)`／`leadEmpty(N)`／`subWindow(N)`／`subSample(M)`／`subPending(C)`／`note`（尾注）——**共 8 键**（`ratioLabel` 已由 D-055 撤除，副标由单键拆为三段）。**参数映射**：`N`＝`window`（窗口天数，默认 30）、`M`＝`samples`（**＝ `retained+lost`，不含 pending**，故副标数字与 rate 分母天然同源）、`C`＝`pending`（未到观察期，不入分母）。**术语对照**：统计学术语 `censored` 即契约的 `pending`，**同一个概念不要再造第三个名字**。**注意 N 与 C 别弄反**：N 是窗口天数、C 是缺口词数。

## 5. 观察缺口（censored）与色彩

**缺口**：只用副标缺口段一行事实说明，**不做任何图表**（无缺口进度条、无第二个大数字）。措辞必须写"**尚未到观察期／未计入分母**"，禁"未答对／忘了／失败"（censored＝未知，不是错误）。C 与 M 同单位（词）。**色彩**：全走既有令牌：主句与比例 `--ink`、标题/副标/尾注 `--ink-soft`、卡面 `--card`、边 `--line`；暗色由 `data-theme` 自动翻转（`--ink` 12.77:1、`--ink-soft` 7.36:1）。**不引入红／绿判定色**：比例不用 `--brand-deep`，两态缺比例时不用 `--danger`／`--warn`／`--brand-soft` 底色块。**不加中性强调线**：层次靠 15px／24px／13px 字级 + `--ink`／`--ink-soft` 明度双降；卡片已有 `.card` 的 `border:1px solid var(--line)`，再画一条线＝重复装饰，分隔就用既有 `.section-gap`。**色彩不承担"区分两个指标"的职责**（见 §6）。**与既有元素的关系**：现有三张图表卡标题都是**时段名**，本块标题「长期答对情况」是行为短语，不与它们同族。本块用**句子里的一个数**编码比例，图表用面积／高度编码量——形态不同即可区分，不靠颜色。本块不得出现 `.heat-grid`／`.bar-chart`／`.bar-col`／`.badge`（胶囊标签＝评级感）。与仪表盘关系：仪表盘是"按强度曲线**估计**的保持率"，本块是"**实际观察**到的再答对比例"；二者**不并排、不互指**（仪表盘 HTML 不在本卡写入域内），同页混读会让用户相减。

## 6. 与「总正确率」的区分：靠位置与措辞，不靠颜色

① **位置**——「总正确率」在页首四卡行第 2 格，本块在三张图表卡**之后**、独立成块，不同行、不同栅格轨道；② **版式**——「总正确率」＝居中格子（30px 绿数字 + 13px 居中标签），本块＝左对齐句子（24px 墨色数字内嵌句中）；③ **措辞**——核心区分词是**窗口**：「总正确率」讲"总"（全时段累计），本块讲"30 天后仍答对"（滞后窗口上的再答），且样本量 M 与比例同句相邻（比例悬空＝无意义小数）。**禁止项**：禁第二个居中大 % 数字、禁"正确率"字样、禁做成 5 卡行第 5 格、**禁用色相区分二者**（用色＝引入评价色）。

## 9. 三个不要

1. **不要做成第五张 `.stat-card`**（含"塞进 `.stat-cards` 栅格"）：会让本比例与「总正确率」并排成两个 % 小卡——正是要防的混淆；且 grid 行高会把现有四卡拉伸出大片死白（量化见 §1）。
2. **不要用颜色或图形表达"好／坏／够不够"**：比例不用 `--brand-deep`，缺比例的两态不用 `--warn`／`--danger`／底色块，禁进度环、进度条、徽章、星级、评级文案；**禁用色相区分本指标与「总正确率」**。
3. **不要为"样本不足／冷启动"造大数字占位**：两态的比例位**整块消失**，只留纯文字；`0%`、`100%`、`—`、`0`、进度环一律不得出现。同时**不做趋势箭头／对比上一期／达标进度条**（慢变量，无第二期数据源），不给窗口加切换控件或下拉（D-054：零新交互）。

## 10. 复用清单、落地校验与移交
