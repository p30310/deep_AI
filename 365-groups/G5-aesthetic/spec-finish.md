## 2. 零评价色：如何落地、为何不用颜色区分表现
- **落地**：全卡只有三档中性文字色——主句/辅助句 `--ink` 与 `--ink-soft`、卡面 `--card`/边 `--line`；主按钮的绿是**全站统一操作令牌** `--cta-bg`，不随对错变化，故它表达「这是主操作」而非「你表现好」。暗色由 `data-theme` 自动翻转令牌，零手写色值。
- **禁止**：禁绿＝好/红＝坏；禁奖杯、勋章、星级、彩带、礼花、进度环/进度条；禁 `--danger`/`--warn`/`--brand-soft` 底色块；禁把 `.badge`（胶囊＝评级感）用在完成页。
- **为何不用颜色区分表现**：① 颜色一旦承载「好/坏」，就把对用户表现的判断强加给用户，与 D-061「不评价」相悖；② 红绿色觉障碍用户不可达；③ #027 已确立「靠位置与措辞、不靠颜色」先例，本卡沿用同一产品语言。

## 3. 空态与异常（0 作答 / 极短会话）
- **同版式、只换句子**：有作答＝主句＋辅助句（`count`）＋两按钮；空态 `answered=0` 时 `count`「作答已保存」为假，故**不渲染 `.fc-count`**，只剩主句（`empty`）＋两按钮。字号/颜色/按钮上方留白**完全不变**（恒 28px，见 §1 `.fc-actions`）——空态绝不变灰（禁用 `--ink-faint` 灰掉）、不缩字号、不居中放一个 `0`。
- **主句走 G1 `empty` 常量**：「这一组没有作答，也没有需要记下的内容。」；不出现 `0%`、`100%`、评级词、`—`、进度环。对齐 #027 `empty` 态教训：**不显示「0 个词」**（0 是「没数据」不是「表现差」），看起来必须像「还没开始」而非「失败」。G5 早先举例「本组 N 词，还没有作答记录」未采用（N=0 会踩 #027 empty 教训），以 G1 `empty` 常量为准。
- **小样本一致口径**：非空的 ≤10 词场景同样**不给比例**——与 #027「样本 <10 不显示比例」同一产品标准，禁止这里显示 `答对占比` 之类变相比例。

## 5. 三个不要（对应派工重点）
1. **不要成绩单感**：无 `%`、无 emoji、无评级标题、无徽章、无居中大数字、无「共 N 词」被读成 KPI 的排版。
2. **不要达标进度条**：无进度环/进度条、无「还差 N 个达标」、无完成度刻度；本页是会话终点，不是待完成目标。
3. **不要鼓励语**：无「完美/不错/加油/继续保持/做得好」；连正面评价也是评价，一律只陈述事实。

## 6. 可访问性
- **对比度**：复用 #021/#022 已修令牌（数值见 §4-12）；把 `.fc-count` 从 `--ink-faint` 改 `--ink-soft` 是本卡必做修复。
- **reduced-motion**：完成页零新增动效；追加一条兜底 `@media (prefers-reduced-motion: reduce){ .finish-card .btn{ transition:none } }` 消除全局按钮 transition 残留（不涉及色值）。
- **读屏顺序**：`h2.fc-lead`（标题/事实句）→ `.fc-count`（辅助事实，仅 answered>0）→ `.fc-actions`（按钮），与 DOM 顺序天然一致；空态为 标题 → 按钮，跳过不存在的辅助句；emoji 节点移除后不再有装饰性朗读。

## 7. 与 #027 的视觉一致性（不混用名称）
- **同调性**：都「不评价、只陈述事实」，都用 `--ink`/`--ink-soft` 两级明度、都不靠颜色区分性质、都不给小样本比例（门槛 10 同标准）；因此两页读起来是同一款克制工具。
- **不混用名称**：#027 叫「**长期答对情况**」（统计页长期观测）；完成页是**本次会话收尾**，禁出现「正确率/答对占比/保持率/长期答对情况/估计」等词，只用 G1 `title`/`summary`/`count`/`empty` 的会话事实措辞。二者措辞不同族：#027 讲「已观察到的…仍答对」，完成页讲「这一组做完了 · N 词已作答 M 个」。
- **形态不同、不强行同款**：#027 是统计页左对齐全宽 `.card` 的句子，完成页是学习页居中的 `.finish-card`；位置与性质不同即已区分，不把完成页做成第二张「长期答对情况」卡。
