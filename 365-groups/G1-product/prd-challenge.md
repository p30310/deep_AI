## 1. 目标与非目标

**目标（可验收）**
- O1 首页首屏（375×667 不滚动）出现「今日挑战」卡与可点按钮，DOM 位置在 hero 卡之后、词书卡之前。
- O2 一次挑战 ≤5 题、无计时、全程不离开首页：开始→答题→关闭期间 `location.hash` 恒为 `#/learn`，路由跳转 0 次。
- O3 挑战全程 0 次 SRS 写入：做完后 `db.words` 逐字段不变，`db.days/goal/settings/exam` 不变，最多新增一条「今天已玩过」事实。

**非目标**
- N1 不评估记忆：无分数/正确率/评级/达标/百分比，不预测遗忘，不做「记住了吗」判断。
- N2 不做排行、分享、连胜、打卡奖励、倒计时、答对音效加成。
- N3 不替代也不改动今日计划、学习页四模式、抽测、错词本、听写、SRS 阶梯与 `w::` 主键。

## 2. 用户故事

- US1 作为「今天有 8 个到期词、只有两分钟」的人，我想在首页点一下做 5 个词，不必打开学习页。
- US2 作为「一进学习页就被几十个词压住」的人，我想先做一小口，结束时看到一句实话，而不是被评分。

## 3. 交互流程

1. 首页渲染：hero 卡之后插挑战卡，即时算池 → 池=0 走 E1；池 1–4 副标题显示实际题数；池≥5 显示默认副标题。
2. 点「开始挑战」：展开覆盖层（不是路由），生成 N=min(5,池) 题，进入第 1 题，`hash` 不变。失败分支：当日已完成 → 不展开，停留完成态。
3. 每题：题头「第 i / N 题」+ 中文释义 + 英文选项按钮（4 个；全库可用词不足时按实际数量，最少 2）。
4. 点选项：立即锁定全部选项（disabled）→ 反馈区出现对/错事实；对错都不给分；重复点击/连点无效。
5. 点「下一题」：i+1；第 N 题的按钮为「看结果」。
6. 第 N 题后：结果视图给一句事实句；写入今日事实（日期键、题数、完成时间），卡片转为完成态。
7. 点「合上」或 Esc：关闭覆盖层回首页，焦点回到挑战卡按钮。
8. 中途「先合上」/Esc/点遮罩（三者同一分支）：不写今日事实、不保存任何作答；toast 提示；**关闭后焦点回到入口卡**；卡片仍可开始；池未变时重开为同一组词、从第 1 题开始。
9. 跨天：日期键不等 → 卡片回到可开始态；昨日事实被覆盖为单条，不留多份。

**空态/失败分支**
- E1 池=0：卡片显示空态句，无开始按钮；点击卡片任意位置不展开、不报错。
- E2 库内可组选项词 <2：不展开，按钮不可用，卡片显示「词库可用词不足 2 个」。
- E3 本地存储写入失败（如隐私模式）：本次仍出结果句、不阻断；仅完成态可能不保留，下次打开可再玩。
- E4 无网络 / 无 TTS / 无 `speechSynthesis`：本功能不使用发音、不加载外部资源，零影响，不出现错误 toast。

## 5. 文案清单（逐字，可直接粘进 `phrases.js`）

| 键 | 逐字文案 | 出现位置 |
|---|---|---|
| `CHALLENGE.title` | 今日挑战 | 卡片标题 |
| `CHALLENGE.sub` | 5 个词，约 2 分钟。不改动学习进度。 | 卡片副标题（池≥5） |
| `CHALLENGE.subShort(n)` | 今天只有 {n} 个词可挑战 | 卡片副标题（池 1–4） |
| `CHALLENGE.start` | 开始挑战 | 卡片按钮 |
| `CHALLENGE.done(n)` | 今天已完成 · {n} 个词 | 卡片完成态 |
| `CHALLENGE.empty` | 今天没有到期的词，也没有错词 | 卡片空态 |
| `CHALLENGE.emptyHint` | 明天再来看看 | 空态下方小字 |
| `CHALLENGE.notEnough` | 词库可用词不足 2 个 | 卡片按钮不可用态 |
| `CHALLENGE.qLabel(i,n)` | 第 {i} / {n} 题 | 题头 |
| `CHALLENGE.ask` | 选出下面释义对应的英文 | 释义上方 |
| `CHALLENGE.optionAria(i,word)` | 选项 {i}，{word} | 选项无障碍名 |
| `CHALLENGE.right` | 选对了 | 答对反馈首行 |
| `CHALLENGE.rightDetail(word,meaning)` | {word} · {meaning} | 答对反馈次行 |
| `CHALLENGE.wrongDetail(word,meaning)` | 这个词是 {word} · {meaning} | 答错反馈（唯一一行，不提用户选项） |
| `CHALLENGE.next` | 下一题 | 非末题按钮 |
| `CHALLENGE.last` | 看结果 | 末题按钮 |
| `CHALLENGE.quit` | 先合上 | 覆盖层退出按钮 |
| `CHALLENGE.quitHint` | 中途合上不算今天完成，也不改动学习进度 | 退出按钮旁小字 |
| `CHALLENGE.quitToast` | 已合上，这次不算今天完成 | 中途关闭后 toast |
| `CHALLENGE.resultPart(n,k)` | 今天这 {n} 个词，{k} 个选对，{n-k} 个没选对。学习进度没有改动。 | 结果页（有错） |
| `CHALLENGE.resultAll(n)` | 今天这 {n} 个词都选对了。学习进度没有改动。 | 结果页（全对，`k=n`） |
| `CHALLENGE.resultNone(n)` | 今天这 {n} 个词都没选对。学习进度没有改动。 | 结果页（全错，`k=0`） |
| `CHALLENGE.close` | 合上 | 结果页按钮 |

> 禁写：得分、正确率、满分、达标、评级、分数、百分比、「你再想想」「别急」「加油」「差一点」。
> `n` 的口径：`subShort(n)` / `done(n)` / `resultPart(n,k)` 的 `n` **恒为实际题数 N=min(5,当次组题时的池)**（`k` 为选对数）；**完成态取落库的当时题数，不按当前池重算**（池事后清空或变大都不许改数）；`optionCapacity` 只用于选项数量与 E2 判定，**不得**拿去渲染任何副标题或结果句。
## 6. 边界与风险

- **池不足 5**：出 N=min(5,池)，**不补未学词、不重复出词**；池=0 走空态。补新词会把挑战变成「学新词」，与定位冲突并诱导跳过今日计划。
- **今天已玩过**：同日不再开局（防止反复刷到全对），卡片显示完成态并带题数；跨天按日期键自动重置。中途关闭不算玩过。
- **中途关闭**：不写任何作答结果、不写完成事实；重开同池同一组词，从第 1 题开始。
- **无 TTS / 无网络**：挑战只用本地词库文本与释义，不发请求、不朗读，断网可完整完成。
- **选项不足 4**：按 `optionCapacity` 实际数量出题（最少 2）；内置 460 词下不会触发，仅自制/删词或大量释义为空时可能出现。
- **池会变**：「今日到期」按 `due ≤ 当日 23:59:59.999` 取，保证同一天内不因上午/下午打开而不同；但用户在学习页评级后池仍会变，故组题只以「打开挑战那一刻」的池为准。
- **最大风险**：用户把「这 5 个都选对」读成「已经掌握了」。因此结果句与卡片必须始终带「学习进度没有改动」，且全流程不得出现任何掌握/记忆判断。
- **次风险**：每天固定一组、固定 5 词，高频用户第二天起边际价值下降；本版不加次数，见 §8。

## 7. 与既有功能的关系（各一句，避免混淆）

- **抽测**（已掌握词 10 个、14 天冷却、统计页发起）：考「会不会写」，未写对的进待重读；挑战考「认不认得出」，每天一次，不写任何状态、不进待重读。
- **听写模式**（学习页 `mode=type&listen=1`）：是完整复习流程，会评级并影响 `due`；挑战只抽看不评级，`lvl/due/st/wrong` 一个都不动。
- **错词本**（`wrong>0` 清单）：是清单与复习入口；挑战只从其中取词出题，不移出、不加 `wfix`、不清空。
- **今日计划**：是「今天该学什么」的唯一入口；挑战只是其中一小口的快捷方式，不改计划、不占额度、不计入 `days.total`。

## 8. G1 备注

1. 任务书「其中几个进了待重读」与红线 2「最多记录今天是否已玩过」互斥：写 `db.exam.flags` 会覆盖抽测的待重读清单，且已超出「最多」范围。本稿按红线 2 执行，结果句只陈述「选对/没选对」；若 G0 要复用待重读，需另出裁决并定义与抽测 flags 的合并规则。
2. 每天一次 + 固定 5 词，高频用户次日边际价值低；建议下一版评估「完成今日计划后解锁第二组」，本稿不自行改设定。
3. 挑战不计入 `days.total` 是刻意的：它是抽看而非学习量，避免用轻点击稀释「有效学习日 / 连续天数」口径。
