01

去塑料感体检An Audit of the Commonplace

工程正确性已经满分：187 个三层令牌、WCAG 2.1 AA、44px 命中区、200 项测试全绿。但正确性可以被复制。这份体检只找一件事——哪些触点在替「通用模板」说话，而不是替这册书说话。

十处病灶与处置

触点现状处置
Ⅰ品牌语「365天，每天进步一点」改「一日一页，词自成书」；副题立下不上传云端的承诺
Ⅱ命名品类描述型，无装帧体系主名保留，增序列名「册页 / FOLIO」，对外以「第几册·第几版」纪年
Ⅲ底色冷中性灰 #F7F7F4 ＋ 纯白卡片暖纸 #F4F1E9；纯白只属于「纸页」
Ⅳ形状14–24px 圆角、渐变封面、浅绿底虚线页签全部直角，撤掉渐变与阴影，激活态改用界栏下压
Ⅴ字体系统字体兜底；衬线只用于词头1.618 韵律字阶，宋体标题／黑体正文，西文 Garamond 本地分发
Ⅵ首屏环形进度＋今日计划数字＋四入口改「扉页」：日期、页码、一个词、一个动作
Ⅶ断更叙事「已断签 47 天」「积压 412 词」「书页停在第 47 页，今日续读一页」
Ⅷ激励小鲸鱼吃一口、加星弹一下、答错抖动桌宠退役；改藏书印与「已装订 N 页」赭金页码
Ⅸ完成反馈按正确率分级的完成页不评级、不庆祝，纸页翻走即可
Ⅹ交付包装双击 exe，直接进首页五幕启封仪式：封缄、题签、授页、入册、闭卷
总　判需要剥离的不是功能，是仪表盘语法与励志模板腔。
功能一条都不必删。

02

美学宪章The Charter

不从外部硬贴一种风格。风格必须从产品已有的物质性里长出来——这件事本身，就是机器无法代劳的判断。

2.1　美学原型：私人书房 · 册页

Logo 是一本打开的书→视觉 DNA 就是「书」，不必另造符号
五种词书 / 单元 / 词条→词书＝册，单元＝章，单词＝页
闪卡 3D 翻转 0.6s→翻卡＝翻页，最古老的交互仪式
26 周热力图→册页年表 / 阅读日历
数据只存本机、无账号→私人书房：不联网，不被人看见
460 词精编，不囤考纲→精编本，拒绝词量军备竞赛
每天翻开一页，一年装订成册。
不是「坚持了 365 天」，是「写完了一本书」。

2.4　空间与留白法则

  1. 一屏一页　任一时刻只保留一个视觉焦点；首屏不放环形进度、不放四个入口。
  2. 三息留白　块间 ≥ 24px，页边 ≥ 48px，章间 ≥ 72px；页边不小于页宽的 1/8。
  3. 界栏而非卡片　1px 细线分区，撤销四级阴影；层级靠留白与墨色深浅表达。
  4. 页码即进度　「第 47 / 365 页」的赭金小字。数字存在，但不占视觉中心。
  5. 齐左不齐中　只有词头与藏书印居中，其余一律齐左。

2.5　微动效：呼吸，不是弹跳

03

数字化开箱仪式The Unbinding

交付的第一分钟决定这件东西值多少钱。首次启动不是「首页」，是「启封」。五幕，不庆祝、不评分、不催促——所有反馈都只是书页状态的变化。

Ⅰ

启封

「这册书只属于这台电脑。」
满纸素白，中央一枚朱印「封」。
空格 → 印淡去，纸面右翻
剥离：直接进仪表盘
Ⅱ

题签

「题上你的名字，这册书便有了主人。」
藏书票、编号、年款。
署名可留空 → 「无名氏」
剥离：无所有权暗示
Ⅲ

授页

「第一页 · 第 1 词」
衬线大字 achieve，一句挖空例句。
空格翻面 → 释义与例句
剥离：首屏任务数字
Ⅳ

入册

「再读一页 / 收进重读 / 此页已装订」
右上角浮出一枚赭金页码。
评级三档逻辑不动，只换文案
剥离：完成页正确率
Ⅴ

闭卷

「今日读到第 1 页。」
纸面合拢，界栏收为一条细线。
「明日续读」或 Esc
剥离：确定退出？/ 太棒了
不庆祝
不评分
不催促
不索取

与既有能力衔接：首词 achieve 取自 cet4 主题重排后的实际首词；空格翻面、评级三档、防误触 180ms、撤销 2.6s 全部保留。错词本、星标、四种模式的逻辑不动，只把入口改名为「待重读的书页」。
与 V2 功能路线不冲突：防积压熔断在美学层叫「重排书页」，记忆强度叫「此页墨色尚浅」——算法照做，不对外展示百分比仪表盘。

无折扣四戒

不打折

不参与大促、不设券、不限时；价格单向上升，老用户锁定购入价。折扣会摧毁藏品属性。

不比价

官网不写高效 / 速记 / 提分 / 领先，不放竞品对比表，不投放效果焦虑。

不试用全功能

只给「试读 7 页」：七词、一次启封、不可导出。门槛本身就是筛选。

不扩量

限定装帧每年 300 册售罄即止，私人词书房每月限 4 单。稀缺必须真实。

审美门槛：首屏不放功能清单、不放价格锚点、不放「立即免费下载」大按钮；只放一页纸、一枚印、一句话。愿意读完题签的人，才是这三档价格的对象。

05

落地路线The Binding

现有三层令牌结构（L1 Primitive → L2 Semantic → L3 Component）恰好支持「只换 L1 值」：组件层引用 L2/L3 的规则无需改动，这让换肤几乎不动业务代码。

阶段动作验收 / 约束
一 · 定调以独立原型验证语汇，评审通过后再进项目主理人确认「册页」原型与本宪章
二 · 换肤只替换 L1 色值、字阶、圆角、阴影令牌200 项 + 设计规范 109 项全绿；dist 四文件逐字节一致
三 · 换文案另立词表，逐条对齐既有「单词 / 已掌握 / 学习中 / 未学」约束无「学会了 / 词汇」违规词，无励志套话
四 · 退役桌宠保留开关但默认关闭，移除喂食与升级叙事排在本期上线之后，不触碰 v1.10「不改桌宠」硬边界
五 · 加装帧首次启动分支＋本地标记，不新增路由老用户不强制重走仪式；SCHEMA 保持 3，数据零迁移
六 · 定价格三层藏品、编号规则、试读 7 页编号唯一不可重号；无折扣写进对外条款

明确不冲突：v1.10 本期硬边界「不新增界面 / 页面 / 组件、不改四种学习模式、不改错词本毕业逻辑、不升 SCHEMA」全部保留。本方案所有界面改造排在阶段二以后，数据层零改动。
不做什么：不删功能、不改算法、不引入框架与 CDN、不做账号与云同步、不用 emoji 与萌系插画、不打折、不把提案写成实测。
