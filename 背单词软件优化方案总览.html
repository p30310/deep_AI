背单词软件优化方案
先止血，再换引擎，最后做体验溢价

核心矛盾不是词不够多、功能不够炫，而是：用户背的是「眼熟」而不是「会用」；复习节奏是算法的而不是他的；一断更就被自己的进度压垮。

北极星指标 次日有效复习完成率 ｜同时反映「计划是否合理」与「用户是否愿意回来」

四个核心痛点

每条痛点都对应一个被拖累的指标，不做无指标的功能
记忆流程

只识别，不提取

点「认识」是再认，考试与使用需要回忆；题型永远停在选择题。

"看着都认识，一写就错"
复习算法

固定阶梯，千人一面

简单词过度复习，难词复习不足；反应时这类关键信号被丢弃。

"简单的天天来，难的天天忘"
任务控制

积压滚雪球

断更 3 天 = 400 词待复习，用户面对的不是任务而是一堵墙。

"断了三天就不敢打开了"
词库与激励

背的不是我的词

无词汇量基线，从 abandon 背起；生词本只进不出，进步不可见。

"除了天数，看不到自己变强"

三大方向 · 十二个方案

P0 = 直接命中流失原因｜P1 = 留存杠杆｜P2 = 差异化体验

记忆效率

让复习发生在即将遗忘的那一刻
A 个体化记忆强度引擎 P0
结果+反应时+自评+词难度 → 每词独立强度 S，反推下次复习点；连续高质量通过即「毕业」。
B 四层训练矩阵 P0
识别 → 回忆 → 辨析 → 运用，随强度自动升降级；多义词按义项拆卡。
C 配比与防积压熔断 P0
复习压力大自动暂停新词；回归时只给 40 词「重建包」，其余摊到 3—5 天。
D 遗忘曲线可视化 P2
把「今天复习完强度 62%→88%」摆到用户眼前，算法从黑箱变伙伴。

学习体验

降低摩擦，制造「我在变强」的证据
E 作答交互重构 P1
单手手势、≤1 秒作答；答错给「差异点讲解」而非排队尾重背。
F 成长型激励体系 P1
休息日冻结 + 补签卡；四条成长线并行，奖励要有质感而非积分。
G 进步可视化周报 P1
强度分布迁移、词汇量曲线、本周「从不会到会用」词单。
H 场景化模式 P2
锁屏 3 词、通勤纯音频、睡前 90 秒错词速览，塞进已有时间缝隙。

个性化

让每个人背「自己的词」
I 目标 → 计划拆解 P1
三问生成可解释计划；每周按完成率再平衡，完不成降量而非制造内疚。
J 词汇量基线 P1
3 分钟自适应测试，直接裁剪已会词，起点从 i+1 开始。
K 真实语境闭环 P2
分级阅读 / 文章导入 / OCR，即点即查一键入本，生词本自动排期。
L 记忆偏好适配 P2
视觉 / 听觉 / 逻辑三种助记风格，按行为自动推断。

三阶段路线图

每阶段有明确的指标承诺，不达标不进入下一阶段
STAGE 01 · 0—6 周

止血与冷启动

低成本、高覆盖，先堵住流失关口
  • C 防积压与回归保护
  • J 3 分钟词汇量测试
  • I 目标与计划生成
  • 首屏与文案重构
D7 留存 +8pp ｜ 回归恢复率 +15pp
STAGE 02 · 6—16 周

引擎替换

决定长期效果，灰度 AB 验证后再全量
  • A 记忆强度引擎（灰度）
  • B 四层训练矩阵
  • E 交互与错误讲解
  • 埋点补齐：反应时 / 自评 / 层级
单位时间掌握词 +25% ｜ 90 天掌握率 +10pp
STAGE 03 · 16 周+

留存与差异化

把留存做厚，形成口碑亮点
  • F 成长激励 + G 周报
  • D 记忆曲线可视化
  • K 语境闭环 / H 场景模式
  • L 记忆偏好
D30 留存 +6pp ｜ NPS +10
质量护栏：假认识率

把「用户点了认识、但在回忆层失败」的比例作为核心质量指标——它直接衡量这次优化到底有没有治好「背了个寂寞」。所有效率类改动都必须同时看这一项与日均时长，避免「减负」被做成「减量」。
